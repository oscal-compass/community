# <img alt="Logo" width="50px" src="./assets/oscal-compass-color.png" style="vertical-align: middle;" /> OSCAL Compass Community

This repository contains the community documentation and governance for the [OSCAL Compass](https://oscal-compass.dev) project, a set of tools that enable the creation, validation, and governance of documentation artifacts for compliance needs.

For full project information, community meetings, communications, and project descriptions, please visit the [OSCAL Compass Community page](https://oscal-compass.dev/community/).

## Repository Contents

This repository contains the following community documents:

- [Contributing](CONTRIBUTING.md) - How to contribute to OSCAL Compass projects
- [Governance](GOVERNANCE.md) - Project governance and decision making
- [Maintainers](MAINTAINERS.md) - Current list of maintainers across all projects
- [Membership](MEMBERSHIP.md) - Contributor roles and membership requirements
- [Security](SECURITY.md) - Security policy and reporting

## Contribution

Our project welcomes external contributions. Please consult [CONTRIBUTING.md](CONTRIBUTING.md) to get started.
