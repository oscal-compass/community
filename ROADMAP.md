# OSCAL Compass Roadmap

This document describes what the OSCAL Compass project intends to do, and not do, over the next year.

## Goals

### 1. Maintain the Codebase

- **Security** — address vulnerabilities promptly and thoroughly in accordance with the project's [security policy](./SECURITY.md)
- **User issues** — triage and resolve reported bugs and feature requests in a timely manner
- **OSCAL schema currency** — keep all tools and artifacts aligned with the latest published NIST OSCAL schema
- **Dependency currency** — keep dependencies up to date to minimize exposure to known vulnerabilities

### 2. Expand Agentic Agile Authoring Skills

Extend the [Agentic Agile Authoring](https://github.com/oscal-compass/agentic-agile-authoring) project with new skills that assist users in authoring OSCAL artifacts, broadening the range of compliance document types and workflows supported.

### 3. Grow the Contributor Community

- Onboard new contributors and guide them toward reviewer and maintainer roles per the [membership process](./MEMBERSHIP.md)
- Improve contributor-facing documentation and reduce barriers to entry
- Increase contributor diversity across companies and organizations to strengthen the project's bus factor

### 4. Advance OpenSSF Best Practices

Achieve OpenSSF Best Practices Silver badge compliance, improving security posture, documentation, and development pipeline maturity.

### 5. Advance Toward CNCF Incubation

Progress the project from CNCF Sandbox to CNCF Incubation status by meeting the [CNCF incubation criteria](https://github.com/cncf/toc/blob/main/process/graduation_criteria.md), including growth in adoption, contributor diversity, and project maturity.

## Non-Goals

The following are explicitly out of scope for the project:

- **Enterprise support services** — the project does not provide commercial-grade support with guaranteed response times
- **Certification authority functions** — the project does not issue compliance attestations or act as a certification body
- **Built-in vulnerability scanning** — the project does not perform active security assessment of documented systems
- **Legacy format support** — the project does not support proprietary compliance management systems or legacy compliance document formats
